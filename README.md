## 💻 Featured Project – Roomify (Airbnb Clone)

A full-stack property listing and booking platform inspired by Airbnb. Built to simplify rental management for hosts and guests with secure authentication and dynamic dashboards.

### 🔧 Tech Stack

- **Frontend:** React.js, EJS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Authentication:** bcryptjs, JWT  
- **File Uploads:** Multer  
- **Rendering:** Server-side with EJS, client-side with React  
- **APIs:** RESTful architecture for listings, bookings, and user actions  

### 📦 Key Features

- Role-based access (Admin, Host, Guest)  
- Secure login and registration  
- Property listing with image uploads  
- Booking system with availability checks  
- Search and filter by location, price, and availability  
- Role-specific dashboards for managing listings and bookings  
- Clean folder structure and documentation for GitHub submission
